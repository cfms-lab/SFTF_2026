잠깐만.
질문이 있어. 1) Bunny 69k의 경우, ★마커의 위치가 세 방법 모두에서 같다는 건 알겠어. 2) 그런데 ★에 표시해준 비용값의
scale이, 세 방법에서 너무 다른걸. 각각 0.0157, 0.0439, 9.99g 이야. 3) 혹시 A,B는 volume 값이고, C는
mass 값인가? 4) 그리고 A와 B 간의 분포가 너무 다른 걸. 이유가 뭘까?



Show less






좋은
질문이에요. 먼저 사소한 정정: 인용하신 0.0157 / 0.0439 / 9.99 g
는 Bunny가 아니라 dragon 그림 값입니다 (Bunny는 0.0236 / 0.0494 / 9.32 g). 논점은 동일하니
그대로 답할게요.



3) A·B가 volume 값인가? → 아니요. 셋 다 서로 다른 양입니다




A (하드 J), B (소프트 L): 부피도 질량도 아닌,
차원 없는 SFTF "점수" 입니다. J = R + P + B인데



R(Rayleigh), P(쌍지지) ~ 면적² (O·A_i·A_j),


B(바닥) ~ 면적×(1+높이) 항이 섞여 있어 자기들끼리도 차원이 균질하지 않습니다.




게다가 bbox 대각=1 로 정규화한 단위 메쉬에서 계산하므로 면적이 "대각선의
분수²" 단위 → 값이 0.01~0.05처럼 작게 나옵니다. 물리량이 아니라 휴리스틱 스코어예요. (부피 비슷한 항 S는 기본 손실에서 꺼져 있습니다, w_supvol=0.)



C
(mss): 진짜 물리
지지 질량(g) 입니다. TomoNV가 메쉬를
120 mm로 스케일해 복셀화하고 재료 밀도를 곱해 계산합니다.




2) 그래서 세 scale이 전혀 다른 게 정상입니다




A·B는 정규화된 추상 점수, C는 실제
그램 — 애초에 비교 불가능한 세 양입니다. 그래서 패널마다 컬러바가 따로이고, 비교 지표도 절대값이
아니라 순위상관(Spearman) 입니다. ★ 라벨은 "그 패널 자체 단위의 비용"일 뿐, 0.0157
vs 9.99 g 를 직접 비교하면 안 됩니다.


A vs B도
절대값이 다른데(0.0157 vs 0.0439), 이는 소프트 완화가 하드보다
체계적으로 위에 떠 있기 때문입니다(softplus 오버행이 0 근처에서 과대평가 + bed_bias 슬롯 상시 가산).
이게 논문이 말하는 점별 갭이고, 온도를 sharpen 하면 mean|L−J|/range가 0.88 → 0.10 으로
줄며 두 값이 붙습니다.




4) A와 B 분포가 달라 보이는 이유



순위상관은
+0.67~0.76(꽤 닮음)인데 눈에는 다르게 보이죠. 세 가지가
겹칩니다:




소프트는 일부러 "뭉갠/평탄화된"
포락선입니다. 하드는 레이캐스트 argmax라 봉우리가 뾰족하고, 소프트는 여러 후보 수신면+바닥에 가중을
퍼뜨려 대비(peak-to-valley)가 작아집니다. 실제로
Bunny에서 J의 상대폭 ≈33%, L ≈22% — L이 더 평탄. (이 "흐릿함"이 바로 미분가능화의 본질이라
봉우리가 약해지고 위치도 약간 이동합니다.)


패널마다 컬러바가 독립 정규화(RdBu_r은 발산형이라 중앙 기준이 패널별로
다름)라, 보이는 건 절대값이 아니라 "각 패널 내부의 상대 패턴"입니다 → 차이가 과장돼 보입니다.





지금 B는 완전 소프트(기본 config) = A로부터
가장 먼 작동점입니다. 담금질로 sharpen하면 A에 수렴합니다(논문 그림 fig:relaxation). 그래도 +0.7대의
순위상관은 거시적 골짜기 구조는 공유함을 뜻합니다.




요약하면
— 세 ★ 값은 비교 대상이 아니라 각 패널 고유 단위의 비용이고,
A·B는 정규화 휴리스틱 점수, C만 물리 질량(g)입니다. A·B의 외형 차이는 "소프트=평탄화된 포락선 + 패널별 색정규화 +
완전소프트 작동점" 때문이며, 순위는 여전히 잘 맞습니다.



원하시면
오해를 줄이도록 다음 중 하나를 적용할게요:




(a) 캡션에 "★ 값은 패널
고유 단위 — 위치를 비교, 값은 비교 금지" 명시


(b) 세 패널을 0~1로
min–max 정규화해
모양을 직접 비교 가능하게(절대값 라벨은 별도 표기)


(c) B를 약간
sharpen한 config로도 같이 보여 A와의 수렴을 시각화
