2. 접목 방안 — 양방향



A. 우리 알고리즘 → 그들 연구 (설명력·확장)




경험 회귀 → 미분가능 기전 모델 승격: P=aε+b를 P=E(nᵀMn)εκ+P₀로 대체 → 소재·동작·부위마다 재측정하던
회귀식을, 물성(Table 2)만 넣으면 예측하는 하나의 모델로 통합.


이방성의 정량화: 그들의 Table 1(웨일 vs 코스
신장률)로 배향텐서 M을 직접 인스턴스화. 예: Nylon_80은 웨일 11.5%/코스
26.4%로 강한 이방성 → M의 방향 가중 (A_i) 비로 인코딩.


스칼라 → 프로파일 역설계: 그들의 도구는 "목표압 1점 → 필요
신장률 1개". 우리는 "목표 프로파일 P*(s)
→ 배향장 θ(s)+신장 분포" → 상완밴드를 위/아래 부위별 차등 설계(그들이
설정한 상완 20cm 구간에 등급 부여).


동작(자세) 차이의 기전 설명: 90° 굽힘 회귀계수↑ = biceps 곡률·접촉
변화 → 우리 κ(s)·O4가 그들이 "향후 보정계수"로 남긴 부분을 채움.




B. 그들 연구 → 우리 프로그램 (실측 grounding)




실측 물성으로 surrogate 보정: Table 2(5종 density·tensile·Ziegert–Keil 신장률)로 우리 E·M을 합성 아닌 실측으로 세팅. 우리 E 보정 노브를 그들의 원통
회귀(R²=.934)로 fit.


실측 의복압으로 O1 보강: 그들의 AMI-3037 원통·인체 압력 = 우리에게
없던 실측 ground truth. 현재 우리 O1은 엔진(cfmsDrape)만; 실측
대비 검증으로 격상.


실 SizeKorea 상완 코호트로 O3 대체: 우리 O3는 합성(실인구 아님).
그들의 SizeKorea 20대 여성 상완둘레 + 10명 피험자 = 실 held-out 데이터(anthropometry.py 상완 버전으로 재산출).


부위 확장 로드맵 정합: 그들의 향후과제(허벅지·종아리·흉부)가 우리 다리
등급별 압박 파이프라인과 직결 → 상완(그들)+다리(우리)=전신 통합.




3. 공동 후속 연구(구체 루프 제안)



역설계 → 제작 → 실측 검증 폐루프:
그들의 5종 원단을 M/E로 인스턴스화 → 우리 역설계로 "목표 프로파일 상완밴드" 패턴(부위별 축소율) 생성 → 그들의
Yuka CAD·제작·AMI-3037 프로토콜로 측정 → surrogate/FE 예측
vs 실측(O1의 실측판). 그들의 실험 강점 + 우리 계산 강점이 한 논문에 결합.



4. 정직성 경계 (과대주장 방지)




우리 것은 hoop 단일곡률 근사이고 엔진은 rank-1
hoop 투영 → 결합 시 우리 예측을 그들 실측으로 검증하는 방향이 정직(반대 아님).


Poly_85(직물)을 그룹화 없이
M/E로 포함할 수 있다는 주장은 검증 필요(그들이 R²로 보인 예외성).


흥미로운 긴장: 그들의 참고문헌 Mosti
& Partsch(2014) "종아리 고압이 gradient보다 중요"는 우리 등급별-단조 가정에 미묘한
반론 → 논의에 반영 가치.







가장 구체적으로 착수 가능한 것은 Table 1/2의 실측값을 우리 orientation.py/pressure.py의 M·E로 인스턴스화해서, 그들의 원통 회귀식(Y=.017X+.372)을 우리 surrogate가 재현하는지 보이는 작은 검증 데모입니다(이게 되면 A-1·B-1이 즉시 실증됨).
