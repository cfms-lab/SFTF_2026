- (Invitation only: Invited Review, Debate, Interview 등 — 해당 없음.)

## 2. 비용 (Publishing fees)
- **Page Charges(필수, 게재 승인 시): $90/page.**
- 컬러 그림: **온라인은 무료 컬러.** 인쇄본 컬러 원할 때만 — 첫 이미지 $800, 이후 이미지당 $200.
- Optional OA: **Sage Choice** 프로그램(별도 비용; 기관 협정 시 할인/무료 가능). OA 비용은 page/color charge와 별개.

## 3. 원고 구조 (Structure & required order)

본문 뒤에 다음 순서로 배치:

1. Title
2. Abstract
3. (본문: Introduction → Materials and Methods → Results → Discussion → Conclusions 등 — 명확한 heading level 사용)
4. **Acknowledgments**
5. **Author Contributions** (CRediT — Acknowledgments 다음)
6. **Statements and Declarations** (아래 하위 헤딩 전부 포함; 해당 없으면 헤딩 두고 'Not applicable' 명시)
   - Ethical considerations
   - Consent to participate
   - Consent for publication
   - Declaration of conflicting interest
   - Funding statement
   - Data availability
7. References

## 4. 제목·초록·키워드 (Title / Abstract / Keywords)
- **Title:** 간결·정확·명확, 내용을 정밀 반영(색인 노출에 영향).
- **Abstract:** unstructured, Original/Review **<300단어** (연구 목적·주요 결과·결론 요약). 임상시험이면 등록정보를 초록 끝에 — SFTF는 해당 없음.
- **Keywords:** **최소 4개**, 초록 뒤에 나열. 주제에 최대한 구체적으로.

## 5. 서식 (Formatting / file types)
- **선호: Word.** 템플릿 불필요하나 heading level·섹션 명확히.
- **LaTeX도 허용** (SAGE Author Gateway에 템플릿).
- PDF는 원고 본문 형식으로 부적합.

## 6. 그림 & 표 (Figures & tables)
- **그림 해상도: 300 dpi.**
- 그림은 본문 등장 순서대로 **연속 번호**(번호 순서대로 게재됨).
- 컬러 그림은 인쇄 여부와 무관하게 온라인 컬러로 표시.
- 타인 저작 그림·표·긴 인용은 저작권자 **허가 취득** 필수.
- (구 Liebert의 900 DPI·CMYK·TIFF/EPS·`SmithFig1` 규칙은 현행 SAGE 지침엔 명시 없음 → SAGE artwork guidelines 별도 확인.)

## 7. 참고문헌 (References)
- **스타일: Sage Vancouver.** (EndNote output 파일 제공.)
- 모든 in-text citation ↔ reference list **1:1 대응** (철자·연도 동일).
- Preprint 인용은 지양; 정식 출판되면 그 버전으로 갱신.

## 8. 저자 기여 (Author Contributions — CRediT)
- **CRediT 분류(14개 역할)** 로 각 저자 기여 기술. Acknowledgments 다음에 'Author Contributions' 헤딩.

## 9. Statements and Declarations (필수 세부)
- **Ethical considerations:** 사람/동물/조직 관련이면 IRB·윤리위 승인(기관명+승인번호). 불필요하면 그 사실을 명시. *→ SFTF는 해당 없음 → 'Not applicable' 또는 불필요 사유 기술.*
- **Consent to participate / Consent for publication:** 개인 데이터 없으면 'Not applicable'.
- **Declaration of conflicting interest:** 이해상충 없으면 정확히 —
  > 'The author(s) declared no potential conflicts of interest with respect to the research, authorship, and/or publication of this article'.
- **Funding statement:** 펀딩 없어도 **반드시 포함**(없으면 그 취지 명시).
- **Data availability:** 데이터 공유 성명 포함(공개 저장소 링크 권장; 불가하면 사유 명시).
- 제3자 작성/편집 도움을 받았으면 Acknowledgements와 cover letter에 명시.

## 10. ⭐ AI / 생성형 AI (SAGE 정책)
- **AI 챗봇(ChatGPT 등)은 저자로 등재 불가.**
- SAGE 정책이 **AI 사용의 적절한 공개**와 **금지된 AI 사용 목록**을 규정. 참조: "Use of ChatGPT and generative AI tools".
- **3단계:** Assistive(문법·표현 개선, 공개 불필요) / Generative(방법·분석·결과·결론에 영향 주는 생성 → **Methods 또는 Acknowledgments에 공개**) / Prohibited(프롬프트 데이터 생성, AI 이미지를 신규 연구 이미지로 제시, 날조 참고문헌, AI 동료심사 등).
- **공개 대상(허용) 명시 항목:** AI 생성/개선 코드, 데이터 시각화, 번역, 문헌조사 보조, 참고문헌 정리.
- **저자가 모든 AI 출력 정확성 검증. 미공개 시 어느 단계에서든 리젝 가능.**

### 이 논문(SFTF)용 AI 공개문 초안
> "Generative AI coding assistants (Anthropic Claude Code and OpenAI Codex) were used to help develop, refactor, and debug the C++/CUDA/Python implementation of the SFTF support-generation algorithm used in this study. All AI-assisted code was reviewed, tested, and verified by the authors, who take full responsibility for the correctness of the methodology, data, results, and conclusions. No generative AI was used to generate research data, figures presented as novel research images, or references."

*(맨 뒤 문장은 사실인 경우에만. 번역·문헌정리에 AI를 썼다면 그 항목 추가.)*

### 작성 중 반드시 점검
- 참고문헌: LLM 환각(존재하지 않는 문헌·틀린 서지) 원본 대조.
- 그림: 전부 자체 파이프라인/렌더러 출력(AI 이미지 생성기 산출 아님).
- 데이터: 자체 시뮬레이션 산출(LLM 프롬프트 생성 아님).

## 11. 투고 (Submission)
- **Sage Track** 온라인 투고(기존 계정 여부 먼저 확인).
- 제출물: 규정에 맞춘 원고 본문 / 그림·이미지(300dpi, 순차 번호) / 보충자료(허용 형식).
- **ORCID:** 제출 저자 ORCID 필수, 공저자도 승인 전 연결 강력 권장(승인 후 추가 불가).
- 전 저자 정보(성명·소속·교신 연락처)는 원고/타이틀과 **정확히 일치**해야 함.
- 투고 시 그림·표·단어 수, 펀더 정보, 이해상충 선언, (있으면) preprint DOI 입력.
- **⚠️ 추천 리뷰어 제출 불가:** "we assign reviewers and cannot accept author recommendations." (구 Liebert의 '리뷰어 3–4명 추천' 규칙은 폐기됨.)

## 12. 피어리뷰 (Peer review)
- Single-anonymized. 리뷰어는 에디터와만 소통. 리뷰 정보 비공개.
- 초기 심사에서 규정 미준수면 반려(수정 요구), 범위 밖이면 데스크 리젝 가능.
- 최종 결정은 Editor(s)-in-Chief.

## 13. 게재 후 (After acceptance)
- **Contributor's Publishing Agreement:** exclusive license(저자가 copyright 보유, SAGE에 독점 출판권 라이선스).
- Proofs는 Sage Edit/이메일로 교신저자에게 — 게재 후 수정 불가, 이 단계가 마지막 기회. **저자 목록 변경 불가.**
- OnlineFirst로 이슈 배정 전 온라인 선공개.
- Preprint 있었으면 최종 출판본 링크를 preprint에 추가.

## 14. ✅ Claude Code 작성 체크리스트
- [ ] **Article type 확정** (원저면 Original Article = **4,000단어**, fig 8/table 5/ref 100)
- [ ] 구조: Title → Abstract → 본문 → Acknowledgments → Author Contributions(CRediT) → Statements and Declarations → References
- [ ] Abstract unstructured <300단어, 인용 없음
- [ ] Keywords 최소 4개(초록 뒤)
- [ ] 파일: Word(.docx) 또는 LaTeX; heading level 명확
- [ ] 그림 300 dpi, 순차 번호; 표는 규정 수 이내
- [ ] References = **Sage Vancouver**, in-text ↔ list 1:1 대응
- [ ] Statements and Declarations 6개 하위헤딩 전부(해당 없으면 'Not applicable')
- [ ] COI 문구 정확히: 'The author(s) declared no potential conflicts of interest…'
- [ ] Funding statement 포함(없어도)
- [ ] Data availability statement 포함
- [ ] **AI 공개문 삽입** (Methods 또는 Acknowledgments)
- [ ] 참고문헌 환각/정확성 검증
- [ ] ORCID 연결, 저자 정보 일치
- [ ] 추천 리뷰어 넣지 않음
- [ ] 최종 SAGE artwork guidelines(그림 규격) 재확인
