# Claude Code 훅 모음 — 설치 안내 (Windows 11)

## 가장 빠른 설치: install.bat 더블클릭

`hooks` 폴더의 **`install.bat`** 을 더블클릭(또는 우클릭 → 관리자 권한 불필요)하면 자동으로:

1. `%USERPROFILE%\.claude\hooks\` 폴더 생성
2. `texdoc-gen.mjs`, `graphify-autoinstall.mjs`, `uv-venv-setup.mjs` 복사
3. `settings.json` 의 훅 설정을 `%USERPROFILE%\.claude\settings.json` 에 **병합**(기존 설정·다른 키는 보존, 같은 이벤트는 갱신, 기존 파일은 `.bak` 백업). 이때 `%USERPROFILE%` 경로는 실제 절대경로로 치환됩니다.

설치 후 Claude Code(및 VSCode 터미널)를 재시작하면 적용됩니다. 아래 수동 설치 내용은 참고용입니다.

# .tex 저장 시 .docx 자동 생성 — 설치 안내 (수동)

VSCode에서 Claude Code가 `.tex` 파일을 저장(Write/Edit)할 때마다, pandoc이 같은 폴더에 `.docx`를 자동 생성합니다. 모든 프로젝트에 전역으로 적용됩니다.

## 1. 파일 두 개 배치

탐색기 주소창에 `%USERPROFILE%\.claude` 를 입력해 폴더를 엽니다. (없으면 만드세요.)

- `texdoc-gen.mjs` → `%USERPROFILE%\.claude\hooks\` 폴더에 넣기 (`hooks` 폴더가 없으면 생성)
- `graphify-autoinstall.mjs` → `%USERPROFILE%\.claude\hooks\` 폴더에 넣기
- `uv-venv-setup.mjs` → `%USERPROFILE%\.claude\hooks\` 폴더에 넣기
- `settings.json` 의 내용 → `%USERPROFILE%\.claude\settings.json` 에 병합

> 이미 `settings.json` 이 있다면 덮어쓰지 말고, 제 `settings.json` 안의 `"hooks"` 블록만 기존 파일에 합쳐 넣으세요. (최상위에 `"hooks"` 키가 이미 있으면 그 안의 `"PostToolUse"` 배열에 항목만 추가)

최종 위치 예시:

```
C:\Users\<사용자명>\.claude\settings.json
C:\Users\<사용자명>\.claude\hooks\texdoc-gen.mjs
```

## 2. pandoc 설치 확인

PowerShell에서:

```powershell
pandoc --version
```

버전이 나오면 OK. "명령을 찾을 수 없음"이 나오면 PATH에 등록되지 않은 것이니, 설치 후 터미널(및 VSCode)을 재시작하세요.

## 3. 적용

settings.json 은 저장 즉시 반영됩니다. 이미 켜져 있던 Claude Code 세션은 한 번 재시작하면 확실합니다.

## 4. 테스트

아무 프로젝트에서 Claude Code에게 `.tex` 파일을 만들거나 수정하게 한 뒤, 같은 폴더에 같은 이름의 `.docx` 가 생기는지 확인하세요. (예: `report.tex` → `report.docx`)

## 비프음 알림 (Stop 훅)

`settings.json` 에 포함된 `Stop` 훅은 Claude Code가 응답/작업을 마칠 때마다 비프음을 냅니다. 별도 파일 없이 PowerShell 한 줄로 동작합니다.

- 음 높이/길이 조절: `[console]::beep(880,250)` 에서 `880` 은 주파수(Hz), `250` 은 길이(ms)입니다.
- 끄기: `settings.json` 의 `"Stop"` 블록을 지우세요.

추가로 `Notification` 훅은 Claude Code가 **사용자에게 권한/선택을 요청하며 멈출 때**(입력 대기) 울립니다. 완료음과 구분되게 더 높은 톤으로 두 번(`beep(1320,150)` ×2) 울리도록 설정돼 있습니다. 끄려면 `"Notification"` 블록을 지우세요.
- 소리가 안 나면: 일부 PC는 시스템 비프(내장 스피커)가 꺼져 있을 수 있습니다. 이 경우 wav 재생 방식으로 바꿀 수 있습니다 —
  `powershell -NoProfile -Command "(New-Object Media.SoundPlayer 'C:\\Windows\\Media\\Windows Notify.wav').PlaySync()"`

## graphify 자동 설치 (SessionStart 훅)

새 리포지토리를 받거나 새 프로젝트에서 Claude Code를 시작하면, `graphify-autoinstall.mjs` 가 자동으로:

1. graphify CLI가 없으면 전역으로 한 번만 설치 (`python -m pip install --user graphifyy` → `graphify install`)
2. 현재 폴더가 코드 프로젝트(`​.git`, `package.json`, `pyproject.toml`, `go.mod`, `Cargo.toml` 등 존재)이고 아직 연동 안 됐으면 `graphify claude install` 실행 → 해당 프로젝트에 `CLAUDE.md` 지시문 + `PreToolUse` 훅 세팅

**전제 조건**: Windows에 Python 3.10+ 와 pip가 설치되어 있어야 합니다. (`python --version` 으로 확인)

**동작 방식 메모**
- `git clone` 자체는 감지할 수 없지만, 받은 리포를 VSCode에서 열고 Claude Code를 시작하는 순간(SessionStart)에 설치됩니다 — 사실상 "새 프로젝트 시작 시 자동 설치"와 동일합니다.
- 코드 프로젝트가 아닌 폴더(예: 홈 디렉터리)에서는 동작하지 않아 불필요한 설치를 막습니다.
- 이미 graphify가 연동된 프로젝트는 건너뜁니다(중복 방지).
- 설치 후 실제 지식 그래프 생성은 `/graphify ./` 로 직접 한 번 실행하세요. (자동 설치는 "연동"까지만 합니다)
- 끄기: `settings.json` 의 `"SessionStart"` 블록을 지우세요.

> graphify는 소스 코드를 외부로 보내지 않고(시맨틱 설명만 전송), MIT 라이선스의 오픈소스입니다. 그래도 전역 자동 설치가 부담되면 SessionStart 블록을 빼고 프로젝트마다 수동으로 `graphify claude install` 을 실행해도 됩니다.

## uv 기반 Python 3.12 + .venv 자동 생성 (SessionStart 훅)

Python 프로젝트에서 Claude Code를 시작하면 `uv-venv-setup.mjs` 가 자동으로:

1. 현재 폴더가 Python 프로젝트(`pyproject.toml`/`requirements.txt`/`setup.py`/`.python-version`/`Pipfile` 또는 루트에 `*.py`)인지 확인 — 아니면 건너뜀
2. `uv` 가 없으면 `pip install --user uv` 로 설치 시도
3. `uv python install 3.12` 로 Python 3.12 준비(이미 있으면 무시)
4. `.venv` 가 없으면 `uv venv --python 3.12` 로 생성, 이미 있으면 건너뜀

**전제**: 가급적 [uv](https://docs.astral.sh/uv/)가 설치돼 있으면 좋습니다(없어도 pip 폴백 시도). 활성화는 평소처럼 `.venv\Scripts\activate` 로 하세요. 끄려면 `settings.json` 의 `"SessionStart"` 배열에서 해당 항목을 지웁니다.
