# SFTF v2.1 후보 동결 (사전 등록) — 2026-07-29

결과 계산 **이전에** 이 문서로 계수와 평가 절차를 동결한다.

## 동결 점수

    S_v2.1(n) = R(n) + 0.25*F_hv(n) + 0.25*F_hm(n) + 0.5*F_bm(n) + 1.0*F_bv(n)

- R: 기존 v2 감쇠 텐서 Rayleigh 항 (변경 없음)
- F_hm = E_A[I_hit·O],  F_hv = E_A[I_hit·O·h]      (h = 수신면 낙하고/D)
- F_bm = E_A[I_bed·O],  F_bv = E_A[I_bed·O·h_bed]  (h_bed = 플레이트 높이/D)
- 비교 기준 V0(현행 v2): S = R + 1.0*F_bm + 1.0*F_bv
- 프로토콜: 2,048 Fibonacci 방향, K=8,192 결정론적 표면 샘플, 임계각 60° —
  모두 투고 논문과 동일. 계수는 Group C 5메쉬에서만 튜닝했고
  (Experimental/R_term_recalib/RESULTS.md), 홀드아웃은 이 평가 전까지
  v2.1 점수로 접촉한 적 없다.

## 평가 대상과 절차

- 대상: TDP v2 외부 홀드아웃 60메쉬 (draft/TDP_v2/experiments/tdp_v2/manifests/
  holdout_manifest.csv, SHA256 검증). 캐시된 dense TOMO 그리드
  (results/tomo_grids/H0xx.npz)만 사용 — 새 TOMO 계산 없음.
- 각 메쉬:
  1. v2.1과 V0 점수를 동일 레이 패스 특징에서 계산.
  2. 논문과 동일한 후보 파이프라인: 24개 12°-NMS 분지 → 캐시 그리드의
     canonical 셀로 2,400셀 확장 → 예산 내 최소 v_ss 셀의 NRR.
  3. V0 재계산 점수가 논문 캐시(sftf_candidate_cache)의 scores_8192와
     일치하는지 sanity check.
- 지표 (사전 지정):
  - 1차: 짝지은 (v2.1 − V0) 정책 NRR, 60메쉬 평균 + 10,000회 부트스트랩 95% CI.
  - 2차: 짝지은 (v2.1 − uniform) NRR (uniform은 논문 external_tomo_results.csv
    값), 방향 스윕 Spearman ρ, top1-NRR, basin24 최소 NRR, 메쉬별 승/무/패.
- 해석 기준 (사전 지정): 1차 지표의 95% CI 상한이 0 미만이면 "개선 확인",
  0을 포함하면 "미확정", 하한이 0 초과면 "악화". 어느 경우든 결과를 그대로
  보고한다.

# 2차 사전 등록 — 타이트 예산 평가 (2026-07-29, 결과 계산 전 동결)

1차 평가(2,400셀)는 지표 포화(무승부 43/60)로 "미확정"이었다. 후보 품질이
승부를 가르는 타이트 예산에서 동일한 동결 점수(v2.1, 위 계수 그대로)를
재평가한다.

- 예산: {5, 10, 20}셀. 후보 선정은 논문 예산 스윕과 동일 —
  24개 12°-NMS 분지를 만들고 canonical 셀을 분지 근접도 순으로 예산만큼 취해
  그 중 최소 v_ss 셀의 NRR을 기록. 캐시 그리드만 사용.
- uniform 기준: 논문과 동일한 결정론적 Fibonacci uniform_cells(예산과 동수).
- **1차 지표: 예산 10에서 짝지은 (v2.1 − V0) 정책 NRR**, 60메쉬 평균 +
  10,000회 부트스트랩 95% CI. 판정 기준은 1차 평가와 동일(CI 상한<0 → 확인).
- 2차: 예산 5·20의 동일 대비, 각 예산의 (v2.1 − uniform) 대비,
  복잡층(≥50k faces, n=25) 부분군의 예산 10 대비, 메쉬별 승/무/패.
- 점수 배열은 재계산 후 npz로 저장해 감사 가능하게 남긴다.

# 3차 사전 등록 — 신규 80메쉬 확증 평가 (2026-07-29, TOMO 계산 전 동결)

2차 평가에서 예산 5의 개선은 CI가 0을 벗어났으나 사전 등록상 2차 지표였다.
이번에는 **한 번도 어떤 점수로도 접촉하지 않은 새 메쉬**에서 예산 5를 1차로
확증한다.

- 표본: `confirm80_manifest.csv`의 신규 80메쉬 (N001–N080).
  - 선정: 기존 프로토콜과 동일한 salted-hash 순서(salt sftf-tdp-v2-holdout-v1),
    동일 기하 검사, 동일 소스(thingi10k_strict), 기존 홀드아웃 60개와 개발
    ID 제외. 계층 할당은 원본 15/20/15/10의 4/3배(20/27/20/13).
  - 근거 표본수: 2차 평가의 예산-5 효과 −0.0242, SD 0.0764 → 80% 검정력에
    n≈80 (α=0.05 양측).
  - 선정 시점에 TOMO/슬라이서 결과는 일절 계산·열람하지 않았다
    (`confirm80_selection_audit.json`).
- 절차: 각 메쉬에 dense TOMO 그리드(1°/60°, INT3, 간소화 없음)를 새로 계산한
  뒤, 동결된 v2.1(위 계수)과 V0를 동일 레이 패스에서 계산, 24-NMS →
  canonical 셀 확장으로 예산 5 정책 NRR을 산출한다.
- **1차 지표: 예산 5에서 짝지은 (v2.1 − V0) 정책 NRR**, 80메쉬 평균 +
  10,000회 부트스트랩 95% CI. CI 상한 < 0 → "개선 확인".
- 2차: 예산 10·20 동일 대비, 각 예산의 uniform 대비, 복잡층(≥50k) 부분군,
  승/무/패, 스윕 Spearman·top1·basin24.
