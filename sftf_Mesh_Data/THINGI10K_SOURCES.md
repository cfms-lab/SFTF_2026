# Thingi10K application cases

Composite-drape-relevant meshes selected from the **Thingi10K** dataset
(doubly-curved single-component manifold shells). Fetched by
`scripts/fetch_thingi10k_cases.py` from the Hugging Face mirror.

**Dataset citation.** Q. Zhou and A. Jacobson, *Thingi10K: A Dataset of
10,000 3D-Printing Models*, arXiv:1605.04797 (2016).
