# Objaverse engineering application cases

Doubly-curved engineering composite **shells** selected from the Objaverse
dataset (Objaverse-LVIS airplane / car / yacht), CC-BY licensed, verified
visually. Fetched by `scripts/fetch_objaverse_cases.py`.

**Dataset citation.** M. Deitke et al., *Objaverse: A Universe of Annotated
3D Objects*, CVPR 2023.
