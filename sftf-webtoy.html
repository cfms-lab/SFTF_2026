Build direction nThe way the part is stood up = screen-up (opposite gravity)
OverhangDownward-facing red faces. Overhang coefficient O = max(0, −m·n)
R termFace–face flow. Rayleigh contraction max(0, −nᵀ sym(F) n) of the tensor F(n)=Σ O/(1+λh/D)·m rᵀ
B termPlate support O(1+λh/D). Amplified with height (face–face is attenuated)
Virtual ground nodeThe plate = a virtual receiver whose normal is n; its Rayleigh contribution is exactly B, so the whole S is one tensor contraction
S = R + BDimensionless total support cost = max(0, −nᵀ sym(F̃) n). Low-S basins are shortlisted as candidates for verification
For each candidate direction n, rays are cast along −n from the overhangs to build the face–face tensor F(n), and the build plate is added as a virtual receiver whose normal is n, so the whole score is one contraction S = R + B. It sweeps 2,048 directions (K=8,192 surface samples) on the sphere, shortlists the low-S basins as candidates, and hands them to accurate verification (TOMO / a slicer). This toy is a 2D slice of that 3D search. · Tip: drag a letter to rotate it, scroll a canvas for the critical angle.
